# Skill: Executive Decision Package

**Purpose:** گردآوری و بسته‌بندی تمامی اطلاعات، تحلیل‌ها، نظرات مخالف و جایگزین‌ها برای ارائه به کمیته اجرایی جهت تصمیم‌گیری نهایی.

**Capabilities:**
- خلاصه‌سازی دقیق از تمامی خروجی‌های مراحل Analysis، Recommendation و Challenge
- تنظیم یک پرونده جامع (Decision Package) شامل: مسئله، داده‌ها، گزینه‌های پیشنهادی، هزینه/ریسک و نظر مخالف
- تعیین سطح دسترسی و محرمانگی مناسب برای هر بخش از پرونده
- استانداردسازی فرم ارائه به کمیته (مدیرعامل، CTO و بنیان‌گذار)

**When to use:** زمانی که تمامی مراحل تحلیل، پیشنهاد و چالش به پایان رسیده است و باید پرونده برای رأی‌گیری نهایی آماده شود.

**Output Format:** یک فایل مارک‌داون با عنوان «Executive Decision Package - [عنوان تصمیم]» شامل بخش‌های: «الزامات»، «گزینه‌ها»، «تحلیل ریسک» و «دستورالعمل رأی‌گیری».
