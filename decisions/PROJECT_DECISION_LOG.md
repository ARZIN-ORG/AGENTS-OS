# Project Decision Log (حافظه رسمی تصمیمات)

**فرمت ثبت هر تصمیم:**

```

---

شناسه تصمیم: DEC-[YYYY]-[XXXX]
تاریخ: YYYY-MM-DD
موضوع: عنوان دقیق تصمیم
پیشنهاددهنده: نام ایجنت / شخص
مراحل طی‌شده: Analysis → Recommendation → Challenge → Executive Review
نتیجه نهایی: APPROVE / REJECT
امضاء کمیته: [بنیان‌گذار] [CEO] [CTO] [مدیر اجرایی]
توضیحات تکمیلی: ...

```

**ساختار پوشه‌ها:**
- `proposals/` : پیشنهادهای اولیه
- `recommendations/` : پیشنهادهای تبدیل‌شده به عملیات
- `dissent/` : نظرات مخالف و گزارش‌های چالش
- `approvals/` : مصوبات نهایی
- `rejections/` : تصمیمات ردشده
- `executions/` : لاگ‌های اجرایی

**ملاحظات:**
- کلیه اسناد باید به‌صورت مارک‌داون و در گیت‌هاب ثبت شوند.
- هیچ تصمیمی بدون ثبت در این لاگ معتبر نیست.
