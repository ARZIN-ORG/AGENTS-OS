# Workflow: Decision

**مرحله:** ۵ از ۶
**وضعیت:** پس از Executive Review
**مسئول تصمیم‌گیری:** کمیته ZDC (شامل بنیان‌گذار، CEO، CTO، و مدیر اجرایی).

**ورودی:** فایل `decision_package_[timestamp].md`.

**فرآیند:**
1. پرونده توسط کمیته بررسی می‌شود.
2. رأی‌گیری انجام می‌شود.
3. در صورت تصویب (APPROVE)، پرونده به مرحله Execution می‌رود.
4. در صورت رد (REJECT)، پرونده به مرحله Analysis بازگردانده می‌شود.

**خروجی:** فایل `final_decision_[timestamp].md` با وضعیت نهایی APPROVE یا REJECT.
