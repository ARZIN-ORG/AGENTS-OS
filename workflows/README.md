# Workflows

**چشم‌انداز گردش کار سازمانی:**
حرکت تصمیم‌گیری در زینوا از این مسیر عبور می‌کند:

Agent (ایجنت) → Analysis (تحلیل) → Recommendation (پیشنهاد) → Challenge (چالش و بازبینی) → Executive Committee (کمیته اجرایی) → APPROVE / REJECT (تصویب/رد) → Execution (اجرا)

هر پوشه در این دایرکتوری، نماینده یک مرحله از گردش کار است. فایل‌های README در هر پوشه توضیح می‌دهند که در آن مرحله چه اتفاقی رخ می‌دهد، چه ورودی‌هایی نیاز است و خروجی نهایی به کجا می‌رود.
