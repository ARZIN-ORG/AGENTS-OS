# Workflow: Execution

**مرحله:** ۶ از ۶
**وضعیت:** پایان گردش کار

**ورودی:** فایل `final_decision_APPROVED_[timestamp].md` از مرحله Decision.

**فرآیند:**
1. ایجنت‌های مرتبط (متناسب با نوع تصمیم) فراخوانی می‌شوند.
2. تصمیم به دستورالعمل‌های عملیاتی تبدیل می‌شود.
3. دستورالعمل‌ها در گیت‌هاب ثبت و برای اجرا آماده می‌شوند.

**خروجی:** فایل `execution_log_[timestamp].md` در پوشه `decisions/executions/` جهت بایگانی نهایی.
