
# Governance Console UX Logic – Executive Mode (Pilot)

- Executive Dashboard shows:
  - 5–10 Insight Cards (prioritized by severity + confidence)
  - Evidence links per card (TraceIDs)
  - "Why" explanation (template-based)
  - "Ask Next" questions (for management discussion)

- Controls:
  - Time window selector
  - Channel filter
  - Policy version selector
  - Governance approve / reject for distribution

- No free-text “chat-to-action”.
Any intent interaction remains in Interaction layer and must go through human confirm flow.
